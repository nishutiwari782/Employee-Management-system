# Employee-Management-system
My First project
Employee Management System

A simple and responsive Employee Management System built using HTML, CSS, and JavaScript.

Features

Add new employees

Edit employee details

Delete employees

Search employees

Employee dashboard

Total employee count

Department count

Average salary calculation

Active / Inactive employee status

Data saved in browser Local Storage

Responsive design for desktop and mobile

Technologies Used

HTML5

CSS3

JavaScript

Browser Local Storage

Project Structure

Employee-Management-System/
│
├── index.html
├── style.css
├── script.js
└── README.md

How to Run

Download or clone the project.

Open the project folder in VS Code.

Open index.html.

You can run it directly in the browser, or use the VS Code Live Server extension.

Add employee details using the form.

Employee Details

The system stores:

Employee Name

Email

Phone

Department

Position

Salary

Joining Date

Employee Status

Data Storage

Employee information is stored in the browser's localStorage. This means the data remains available in the same browser until its local storage is cleared.
